# Tahm v1.0.1

[简体中文](v1.0.1.zh-CN.md) · [Download the Windows x64 portable build](https://github.com/la8garlic/Tahm/releases/tag/v1.0.1)

The portable ZIP includes the updated [English README](../../README.en.md), [Chinese README](../../README.md) and four screenshots captured from v1.0.1. Extract the whole ZIP to view the [scan center](../screenshots/scan-center-en.png) and [cleanup suggestions](../screenshots/cleanup-en.png) offline, including the **Rebuild evidence** and **Manual review** groups.

To upgrade, close the previous version and download `Tahm-v1.0.1-windows-x64.zip` and `SHA256SUMS.txt` from the same release. Follow the README to verify the download, extract the ZIP and start `Tahm.exe`. The title bar shows **v1.0.1**.
