# 塔姆 v0.9.0

[English](v0.9.0.en.md) · [下载 Windows x64 便携版](https://github.com/la8garlic/Tahm/releases/tag/v0.9.0)

- 普通扫描后，面积图上方会直接显示一条清理建议及其依据。点击「查看全部」可以按类别筛选和翻页。仅想找清理候选项时，可在扫描中心点击「扫描并查看建议」。
- 建议列表逐项显示文件被列入的原因和可以清理的条件。核对归档是否另有完整副本、安装包是否还需要修复软件后，再决定是否加入清单。移入回收站仍需单独确认。
- 扫描复用同一文件句柄查询到的元数据。磁盘占用和预计释放量继续考虑硬链接。
- 标题栏显示版本号，界面与 Windows 可执行文件采用同款磁盘分析图标。

下载 ZIP 和同版 SHA256SUMS.txt，按[使用说明](../../README.md)校验后解压运行。系统需要 WebView2 Runtime；此版 EXE 未使用 Authenticode 签名。
