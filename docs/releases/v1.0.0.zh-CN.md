## 清理建议

- **有重建依据**优先展示能找到项目线索的目录。Node 依赖需要同级项目清单和锁文件，Rust 构建目录需要 Cargo 清单和编译器标记，Python 字节码缓存需要每项都有对应的本地源码。移除前仍需核对依赖来源、手工修改和需要保留的成品。
- **需人工判断**收录归档、安装包、下载分片，以及缺少重建线索的项目。扫描仅凭扩展名识别归档类型；如要确认两个文件内容相同，可在文件详情中点「查找相同内容」。
- 两组分别计数、排序和分页。扫描结果、项目详情及待清理清单会显示判断依据。扫描完成后由你选择项目，确认后才会移入系统回收站。[查看清理建议界面](../screenshots/cleanup-zh-CN.png)

## 升级与报告

关闭旧版，将便携包解压到新目录并启动 `Tahm.exe`。系统需要 WebView2 Runtime。下载同版 `SHA256SUMS.txt`，按[启动说明](../../README.md)核对 ZIP 的 SHA-256。

如果有脚本读取导出的 JSON 报告，请改读 `reviews.rebuild` 和 `reviews.manual`。每组分别包含 `count`、`categories` 和 `items`，条目的 `advice.review` 取值为 `"rebuild"`、`"manual"` 或 `null`。
