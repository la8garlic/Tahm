# 塔姆 v0.8.0

[English](v0.8.0.en.md) · [下载](https://github.com/la8garlic/Tahm/releases/tag/v0.8.0)

首个公开版本面向 Windows x64。下载便携 ZIP 和 SHA256SUMS.txt，按[启动说明](../../README.md)校验、解压并运行 Tahm.exe。需要 WebView2 Runtime。程序内嵌 MiSans，可离线显示中英文界面。

- 在面积图与目录明细之间双向定位，切换逻辑大小与磁盘占用。跨目录选择多个项目时，合并父子选区并去重硬链接。
- 清理前可查看清空回收站后的预计释放量。确认后逐项复核，列出移入结果和失败原因。其他应用写入和文件系统元数据会影响最终可用空间。
- 可按文件类型、目录大小、时间与扫描历史调查旧文件夹，也可主动比对相同内容。可选模型解读支持先预览目录线索，再由用户决定是否发送。
- 项目代码采用 Apache-2.0，字体和依赖协议随便携包提供。首发 EXE 未使用 Windows Authenticode 签名。
