## Cleanup suggestions

- **Rebuild evidence** appears first when the scan finds supporting project files. Node dependencies need a sibling manifest and lockfile, Rust build output needs a Cargo manifest and compiler marker, and every file in a Python bytecode cache needs matching local source. Check package availability, local edits and build artifacts you want to keep before removal.
- **Manual review** covers archives, installers, partial downloads and items with missing rebuild evidence. A filename extension identifies an archive format. Use the content comparison action in file details to check whether two files are identical.
- Each group has its own count, size ranking and pagination. The scan summary, item details and cleanup queue show the basis for review. Choose the items you want and confirm before moving them to the Windows Recycle Bin. [See the suggestions screen](../screenshots/cleanup-en.png)

## Upgrading and exported reports

Close the previous version, extract the portable ZIP to a new folder and start `Tahm.exe`. WebView2 Runtime is required. Download the matching `SHA256SUMS.txt` and follow the [startup guide](../../README.en.md) to verify the ZIP's SHA-256.

Scripts consuming exported JSON reports should read `reviews.rebuild` and `reviews.manual`. Each group contains `count`, `categories` and `items`. An item's `advice.review` is `"rebuild"`, `"manual"` or `null`.
