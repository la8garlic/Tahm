# Tahm v0.8.0

[简体中文](v0.8.0.zh-CN.md) · [Download](https://github.com/la8garlic/Tahm/releases/tag/v0.8.0)

The first public release is available for Windows x64. Download the portable ZIP and SHA256SUMS.txt. Follow the [startup guide](../../README.en.md) to verify the archive, extract it and launch Tahm.exe. WebView2 Runtime is required. Embedded MiSans supports both interface languages offline.

- Navigate between treemap tiles and directory rows. Switch between logical and allocated size, retain selections across folders, and count nested entries and hard-linked data once.
- Preview the space expected back after emptying the Recycle Bin. On confirmation, Tahm rechecks each queued item and reports individual outcomes. Concurrent writes and filesystem metadata can affect free space.
- Investigate old folders by file type, size, age and scan history, or explicitly compare identical contents. Preview the selected folder evidence before sending it for an optional model explanation.
- Project code uses Apache-2.0. The ZIP includes separate font and dependency notices. The executable ships without a Windows Authenticode signature.
